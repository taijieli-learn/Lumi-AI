# Lumi Product Demo

This folder is for the product demo, not the marketing landing page.

The demo should behave like a small interactive app prototype:

- show user context from cross-app saved items
- let Lumi identify an intent pattern
- show a proactive Lumi card
- generate a lightweight action card
- close the loop by updating the user's growth memory

Keep the first version click-through and mock-data driven. The goal is to prove the interaction and product mechanism before building real integrations.
