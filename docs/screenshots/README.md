# Screenshot Archive

This folder stores visual iteration screenshots and QA captures.

Do not put screenshots in the project root. Keep the root focused on source control, package config, and project docs.

## Folders

| Folder | Purpose |
| --- | --- |
| `definition-landing/` | Landing page definition-section experiments and responsive captures |
| `final-candidates/` | CTA/final-section and demo-related visual candidates |
| `visual-checks/` | Focused QA screenshots used to inspect a specific layout or visual issue |

## Rules

- Use screenshots for decision history and visual comparison only.
- Put production assets in `client/public/assets/lumi/`, not here.
- Name new screenshots with the page or component first, then the viewport or variant.
- Keep only useful visual checkpoints. Delete or archive noisy duplicates once a direction is settled.
